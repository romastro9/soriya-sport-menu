# SORIYA SPORT Menu

Customer catalog without prices: jersey portfolio, 40 fabric choices and 29 neckline styles.

## Hosting
Deploy the `site/` directory as a static website on Vercel. No build or dependencies required.

The jersey portfolio refreshes from the existing public gallery manifest at https://romastro9.github.io/soriya-sport/jersey-manifest.json. That gallery is updated from the approved Google Drive folder by the original project. Fabric and neckline assets are bundled here.
